Nota metodológica. Dados de Yeh, I. (2009), Default of Credit Card Clients, UCI Machine Learning Repository, licença CC BY 4.0. O histórico de abril a setembro de 2005 é usado para prever a inadimplência no mês seguinte. A documentação do dataset diz apenas "mês seguinte" (next month); como o histórico termina em setembro, esse mês é outubro. O modelo (regressão logística) foi treinado em 70% da base e avaliado nos 9.000 clientes restantes. Valores monetários em dólares de Taiwan (NT$). A taxa ajustada pelo limite é a média das taxas de cada faixa etária dentro de cada faixa de limite, ponderada pela distribuição de limites da base inteira (padronização direta).
